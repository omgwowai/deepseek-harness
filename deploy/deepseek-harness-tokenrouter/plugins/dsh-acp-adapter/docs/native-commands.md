# 原生 Agent 的斜杠命令与快捷交互

[English](native-commands.en.md)

适用于以原生协议运行的 Claude Code 2.1.296、Codex 0.162.1、Oh My Pi 18.12.6 路由（DSH `0.2.1-rc.2`）。每个路由把自己的命令目录登记为会话级 DSH 命令：输入 `/` 即可在菜单里看到，`/help` 列出当前 Agent 的全部命令和运行方式。设计与边界见 [原生复用与保留边界](native-reuse.md)。

图例：✅ 立即返回，不调用模型，不产生轮次；✅轮 作为下一轮发给 Agent（与原有 `/compact` 相同）；◐ 部分支持；✗ 该 Agent 没有可用的机器协议。

| 命令 | 作用 | Claude Code | Codex | Oh My Pi |
|---|---|---|---|---|
| `/btw <问题>` | 旁路提问，主任务照常运行；答案只显示在 DSH，不进入 Agent 对话 | ✅ | ✅（另有 `/side`） | ✅ |
| `/clear`、`/new` | 清空 Agent 上下文；重启后不会恢复已清空的内容 | ✅ | ✅ | ✅ |
| `/compact` | 压缩上下文 | ✅轮 | ✅轮 | ✅轮 |
| `/rewind` | 回退到某条消息之前：`/rewind` 列表、`/rewind <n>` 预览、`/rewind <n> confirm` 执行，可加 `code` / `chat` 只回退文件或对话 | ✅ 文件（检查点）+ 对话 | ✅ 文件（反向应用 Agent 记录的改动，冲突时不动）+ 对话 | ✅ 对话（从该点分出新会话）；文件：`edit` 的改动可回退，`write` 写入的文件因无旧内容记录列为不可恢复 |
| `/goal` | 原生目标模式：`/goal` 查看、`/goal <目标>` 设定、`/goal clear` 清除，部分支持 `pause` / `resume` | ✅轮（CLI 原生目标） | ✅轮（目标推进期间该轮保持打开，Stop 暂停目标） | ✅轮（目标推进期间该轮保持打开，Stop 暂停目标） |
| `/plan` | 计划模式；`/plan off` 恢复原模式 | ✅ 原生计划模式 | ✅ 原生 Plan 协作模式 | ◐ 仅 DSH 文本计划（omp 接口不提供计划模式） |
| `/effort [级别]` | 推理强度，与模型菜单同步 | ✅ | ✅ | ✅ |
| `/fast` | 快速模式 | ◐ 该通道下 Claude 不开放 | ◐ 仅在模型提供 Fast 档时 | ✅（另有 `/slow`） |
| `/model` | 换模型 | DSH 模型菜单 | DSH 模型菜单 | DSH 模型菜单 |
| `/status` | 会话状态 | ✅ | ✅（含目标、额度） | ✗（可用 `/session`，✅轮） |
| `/context` | 上下文占用 | ✅ | ◐ 见 `/status` | ✅轮 |
| `/usage`、`/cost` | 用量与费用 | ✅ | ◐ 见 `/status` | ✅轮 |
| `/mcp` | MCP 状态与重连 | ✅ | ✅ | ✅轮 |
| `/skills` | 技能列表 | ✅ | ✅（可启用/停用） | ✗（技能仍可直接调用） |
| `/memory` | 记忆文件 | ✅ 只读 | ✗ | ✅轮 |
| `/hooks` | Hook 列表 | ✅ | ✅ | ✗ |
| `/tasks`、`/ps`、`/jobs` | 后台任务 | ✅ `/tasks`（可停止、看输出） | ✅ `/ps`、`/stop` | ✅轮 `/jobs` |
| `/diff` | 未提交改动 | ✅ | ✅ | ✗ |
| `/permissions` | 权限规则 | ✅ 只读 | DSH 模式菜单 | DSH 模式菜单 |
| `/init`、`/review` | 生成说明文件、代码审查 | ✅轮 | ✅轮 | ✅轮 |
| `/rename` | 改会话名 | ◐ 只改 Agent 内部名称 | ◐ 同左 | ◐ 同左 |
| `/help` | 当前 Agent 的命令与运行方式 | ✅ | ✅ | ✅ |
| `!命令` | 直接在 shell 执行，不调用模型 | ✅ | ✅ | ✅ |
| 自定义命令、skill、插件命令 | Agent 自己的扩展命令 | ✅轮 | ✅轮 | ✅轮 |
| `/export`、恢复、分叉 | 会话管理 | DSH 自带 | DSH 自带 | DSH 自带 |
| `/theme`、`/vim`、`/login` 等 | 终端界面与账号 | 返回说明，不发给模型 | 同左 | 同左 |

限制：

- 工具审批卡打开时 DSH 用卡片替换输入框，需先处理审批再输入命令。
- 尚未发送消息的空白会话里不显示命令结果，发出首条消息后在历史中可见。
- DSH 会话记录只追加：`/rewind` 和 `/clear` 之后，被回退或清空的消息仍显示在 DSH 中，但 Agent 已不再记得。shell 命令造成的副作用不会被回退。
- Claude Code 在后台任务完成后自行发起的回合不会显示（需要宿主侧的任务唤醒支持）。
