# Agent Fleet panel (dev notes)

Vanilla JS + SVG, no build step, no framework, no network access beyond the hub's own `api/*`. Served by the hub
(`lib/hub/http.mjs`) at `/` and under `/fleet/` behind the edge router; every URL in the page is relative.

| File | Role |
|---|---|
| `index.html` | Static shell: tabs, toolbars, empty containers, SVG icon sprite. CSP is `default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self'`. |
| `app.css` | Theme (CSS variables, `prefers-color-scheme`), dense layout. |
| `app.js` | Everything else; one IIFE, sections: pure helpers · DOM kit · store · transport · views · boot · demo hub. |
| `fixtures/demo.json` | Synthetic snapshot + per-agent events + file previews + kube events for `?demo=1`. Generated by `fixtures/make-demo.mjs` (deterministic). |

## Run it without a hub

```sh
cd plugins/dsh-agent-fleet/panel
/Users/lbc/.local/dsh/lib/node_modules/node/bin/node -e "require('http').createServer((q,r)=>{const f=require('path').join(process.cwd(),q.url.split('?')[0].replace(/\/$/,'/index.html'));require('fs').readFile(f,(e,b)=>{r.writeHead(e?404:200,{'content-type':f.endsWith('.js')?'text/javascript':f.endsWith('.css')?'text/css':f.endsWith('.json')?'application/json':'text/html'});r.end(b)})}).listen(8790,'127.0.0.1')"
# open http://127.0.0.1:8790/index.html?demo=1
```

`?demo=1` loads `fixtures/demo.json`, shifts every timestamp so the fixture's "now" is the real now, and runs an
in-page hub (`createDemo`) that serves the same `api/*` surface and emits a delta about every 1.1 s: running agents
start/finish tool calls, the server OMP session spawns and retires a subagent, host lag jitters. `?demo=1&speed=3`
divides tool durations and think times by 3 (the delta cadence stays at ~1.1 s). In the console, `__fleet.demo.setOnline(false)` drops the "connection" (banner +
auto-reconnect) and `setOnline(true)` heals it.

## Data contract the panel relies on

| Request | Response |
|---|---|
| `api/snapshot` | `Snapshot` (`protocol.mjs`); optional `sources: {[site]: {status:"online"\|"unreachable", error?}}` for the kube watch state on the site cards. |
| `api/stream?since=N` | SSE, `event: delta`, `data: Delta`. An initial delta on connect is fine. `reset:true` makes the panel reload the snapshot. |
| `api/changes?since=N` | `Delta` (at least `cursor`, `now`). Polled every 1 s when SSE is unavailable, probed every 10 s on a quiet stream. |
| `api/family?key=K` | `{root, agents[], links[], events:{[agentKey]: AgentEvent[]}}`, events oldest → newest. |
| `api/agent?key=K&before=<t>&limit=N` | `{key, events[], hasMore}`; `before` is an exclusive upper bound on `event.t`. Without `before`: the newest page. |
| `api/pods` | `{pods: Pod[]}` |
| `api/pod?key=K` | `{pod, touches:[{agent,event,t,op,category,name?,preview?}], events:[{type,reason,message,count,firstSeen,lastSeen}]}` |
| `api/file?host=H&path=P` | `FilePreview` |
| `api/query?target=pod\|file&category=a,b&since=ms&limit=N` | `{items:[{agent, event}]}`; used to complete the pod/file touch index beyond what the feed carried. |
| `api/hosts` | `{hosts: Host[]}` (not required; hosts arrive in the snapshot and deltas). |
| `POST api/session` (header `x-agent-fleet-nonce`) | `{session}`: the panel session key for the plugin's `#nonce=…`; `401` for a spent or expired nonce. |

Errors are `{error}` with an HTTP status; `401` shows an "unauthorized" banner. A credential in the URL fragment is
removed from the address bar and kept in page memory only (never `sessionStorage`/`localStorage`): `#nonce=…` (the
plugin's panel URL) is redeemed once with `POST api/session` for a session key, `#token=…` (manual entry) is used as
is and also exchanged for the HttpOnly cookie. Either goes out as `x-agent-fleet-token`, and the stream then uses
`fetch` instead of `EventSource` (which cannot set headers). Without one the page relies on the cookie (set by
`/?token=`) and the plain `EventSource`. The header is what works when the panel is an iframe of another site (the
desktop app's dsh-app:// page), where the browser withholds the SameSite cookie.

## Behaviour notes

* **State** is one store (`S`): hosts/agents/pods keyed maps, `links`, per-agent event stores (sorted lists + id maps,
  upserted by event id so a pending tool turns into a finished one), pod/file touch indexes derived from event targets,
  feed. Deltas mutate the store and schedule one render (≤ 8/s). Lists are reconciled by key (`reconcile`) so rows are
  reused, not rebuilt; a row's HTML is only rebuilt when its signature changes.
* **Clock**: `snapshot.now` and every delta's `now` are folded into `S.clockOffset`, so "age", the now-line and pending
  durations follow the hub clock even when the browser clock is skewed.
* **Fleet tree**: sites → hosts/pods → family trees built from `links` (falling back to `parent.key` hints). A child on
  another host is rendered under its parent with a `↗ host` badge and is also listed greyed under its own host.
* **Timeline**: lanes are packed by interval colouring (`packLanes`: roots on their own lane, children inside the parent's
  block, host-pure lanes). Only lanes inside the scroll window and ticks inside the time window are emitted, merged per
  pixel (`merge distance` grows with density, hard budget of 14 000 elements per frame); hit-testing is geometric, so
  hover/click do not need DOM nodes. Redraw: 1 Hz tick while the view is open plus on data change; zoom/pan/brush redraw
  on `requestAnimationFrame`. The "active axis" collapses 1-minute-bucket gaps longer than 15 min to 90 s.
* **Hash**: `#view=…&key=…&site=…&kind=…&q=…&focus=<dshSessionId>`; `focus` resolves to the DSH session, else the native
  session bound to it over ACP, and selects its family root.

## Tests

`node --test tests/panel.test.mjs` loads `app.js` in a DOM-less `vm` context (it then only exports its pure helpers) and
checks the helpers, the drift against `lib/protocol.mjs`, and the structure of `fixtures/demo.json`.
